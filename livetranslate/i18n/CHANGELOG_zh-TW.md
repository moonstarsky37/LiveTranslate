# 更新日誌

## 2026-08-08 (v2026.08.08-tw.5)
- 新增 SenseVoice ONNX 辨識引擎 (設定 → 辨識 → 引擎): 同一個模型的 ONNX int8 版本, 走 CPU 不需要顯卡。ASR 啟動從 56 秒降到約 2 秒, 模型 936MB 降到 239MB, 辨識速度與原本的 GPU 版相當; 顯卡空出來給翻譯用。原本的 FunASR 引擎維持不變, 兩者可隨時切換
- 首次啟動的初始設定新增辨識引擎選擇: 預設是 SenseVoice ONNX (下載 239 MB, 不需顯示卡), 也可改選 FunASR 版 (下載 936 MB, 用 GPU 推理)。選擇會影響首次下載的內容, 之後仍可在設定中更改

## 2026-08-08 (v2026.08.08-tw.3)
- 安裝流程改用 uv: 不需要事先安裝 Python, 安裝腳本會取得 uv 專用的 Python 3.12, 不再獵尋 (或誤用) 系統 Python
- 修復 install.bat 把虛擬環境建在 `scripts\` 底下、導致 start.bat 找不到環境的問題 (影響 v2026.08.07-tw.1 起的原始碼安裝)
- 浮窗監控列新增 ASR 狀態: 載入中 / 無法使用一目了然, 啟動與切換引擎期間不再像是當掉
- ASR 模型載入後先跑一次暖機推論: 載入完成後的第一句不再多等 5-6 秒
- 暫停時把講到一半的句子送出辨識再清空緩衝: 恢復後不再冒出暫停前的陳舊語音, 那半句也不會憑空消失 (與關閉程式時的行為一致)
- 設定 → 辨識新增「最低語音密度」滑桿 (設 0 關閉): 停頓多的來源 (剪過的影片、講話慢) 不再被整段當噪音丟棄
- 設定 → 快取新增 HuggingFace token (選填): 解除匿名下載限流, 內容不會寫進日誌
- 修復下載時「unauthenticated requests」英文警告重複出現 (huggingface_hub 1.27 會在載入時覆蓋日誌等級, 改用環境變數壓制)
